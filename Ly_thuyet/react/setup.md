1. Tạo project React bằng Vite:
(Nhanh, nhẹ, khuyên dùng cho người mới)
Vite là công cụ hoàn hảo để tạo các ứng dụng React thuần túy (Single Page Application) nhờ tốc độ cực nhanh.
Mở terminal và chạy lệnh:
`npm create vite@latest ten-du-an -- --template react`

(Nếu bạn muốn dùng TypeScript thay vì JavaScript, hãy đổi react thành react-ts)


2. Tạo project React bằng Next.js (Khuyên dùng cho dự án thực tế)
Hiện tại, đội ngũ React chính thức khuyên lập trình viên nên sử dụng Next.js để xây dựng ứng dụng vì nó hỗ trợ sẵn các tính năng tối ưu SEO, Server-Side Rendering (SSR) và cấu trúc thư mục rõ ràng.

Chạy lệnh sau:
`npx create-next-app@latest ten-du-an`
